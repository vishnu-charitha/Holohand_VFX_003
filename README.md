# Real-Time Hand Tracking Hologram System

A computer vision–based project that implements real-time hand tracking and holographic visual effects using Python, OpenCV, and MediaPipe. The system detects hand movements through a webcam and generates interactive futuristic visual overlays, creating an immersive gesture-controlled experience.

## Overview

This project demonstrates the integration of computer vision and gesture recognition techniques to create a real-time visual effects system. By leveraging hand landmark detection, the application produces holographic overlays and dynamic visual interactions based on user hand movements.

## Features

- Real-time hand detection and tracking
- Gesture-based visual interaction
- Holographic overlay effects between detected hands
- Dynamic glow and visual enhancement effects
- Interactive computer vision implementation
- Lightweight and beginner-friendly architecture

## Technologies Used

- **Python** – Core programming language  
- **OpenCV** – Real-time image and video processing  
- **MediaPipe** – Hand landmark detection and tracking  
- **NumPy** – Numerical computations and processing

## Working Principle

The application captures live webcam input and processes frames using MediaPipe hand tracking. Detected hand landmarks are analyzed to generate dynamic holographic effects and gesture-based visual overlays in real time.
